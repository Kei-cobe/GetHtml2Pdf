📄 网页 PDF 控制台

⚙️ 首次使用请先在「设置」里填入 GitHub Token（只会保存在你这部手机的浏览器里，不会上传到任何地方）。

⚙️ 设置

展开 / 收起

📋 定时任务（网址 + 备注）

点「从仓库读取」加载当前 tasks.json

只需填备注名和网址；若内容在 iframe 里会自动识别并完整打印。

⏰ 定时设置（北京时间）

点「读取定时」加载当前设置

按北京时间设置，会自动换算成 UTC 写入工作流。保存后约 1 分钟生效。

🚀 立即执行

点上方「从仓库读取」加载任务卡片，或先在「定时任务」里添加并保存。

点击卡片选中/取消，支持多选；选中后点执行，PDF 会发到你的邮箱 / 企业微信 / 微信。
